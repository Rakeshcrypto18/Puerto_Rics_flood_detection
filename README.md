
**Flood Detection and Extent Mapping using Sentinel-1 SAR Data for Puerto Rico**

This repository contains the workflow, scripts, and supporting data for the **Hydrowatchers** DAEN 690 Term Project.  
The objective is to detect and map flood extents in selected regions of Puerto Rico using **Sentinel-1 SAR** imagery (VV/VH polarizations) and **Digital Elevation Models (DEM)** from the **Copernicus Open Data Hub**.

---

## 🗺️ Overview

1. Define **cells (areas of interest)** within Puerto Rico using QGIS.  
2. Download **pre-flood** and **post-flood** Sentinel-1 images via the Copernicus API.  
3. Process **VV/VH** backscatter and **DEM** data for each cell.  
4. Convert GeoTIFFs → CSV for per-pixel analysis.  
5. Detect flood-affected pixels using thresholding and slope filtering.  
6. Generate **flood-extent shapefiles** for visualization in GIS software.

## 🗺️ Step-by-Step Workflow

### 1️⃣ Define Cells / AOIs
- Use **QGIS** to create a grid overlay on Puerto Rico.  
- Each grid cell (1–5 in the initial iteration) represents an area of interest small enough to allow **10 m/pixel resolution**.  
- Reference: `puertorico_grid.xlsx` for grid coordinates and boundary points.

### 2️⃣ Connect to Copernicus API
- Validate Copernicus credentials.  
- Run:
  - `process_api_connection.py` → Downloads VV (band 1) and VH (band 0) imagery.  
  - `dem_process_api.py` → Downloads DEM data for slope calculations.  
- Pull **3 pre-flood** and **2 post-flood** images per cell.  
- TIFFs are stored under `geo_tiffs/` with the format:

*(01 = cell ID, “1” = image number)*

├── process_api_connection.py # Pulls Sentinel-1 VV/VH imagery for defined cells
├── dem_process_api.py # Pulls DEM data for slope analysis
├── geotiff_to_csv.py # Converts GeoTIFFs to coordinate-value CSVs
├── slope.py # Calculates slope values from DEM CSVs
├── initial_flood_extent.py # Merges data and applies thresholding for initial flood extent
├── flood_extent_filtering.py # Applies logical filters (area, slope, mean change) for final extent
│
├── geo_tiffs/ # Folder storing downloaded VV/VH/DEM GeoTIFFs
├── geotiff_csvs/ # Folder storing CSVs converted from GeoTIFFs
├── puertorico_grid.xlsx # Grid boundaries and coordinates for Puerto Rico cells
└── README.md # Project documentation

### 3️⃣ Convert GeoTIFFs → CSV
- Run `geotiff_to_csv.py` for each cell’s VV and VH GeoTIFF.  
- Each CSV contains pixel coordinates and corresponding backscatter values.

### 4️⃣ Generate Slope Data
- Run `slope.py` to compute slope values from DEM CSVs.  
- Output: slope values per pixel saved as new CSVs for later filtering.

### 5️⃣ Detect Initial Flood Extent
- Run `initial_flood_extent.py`:  
- Merges all CSVs across cells.  
- Computes **mean change** between pre- and post-flood images.  
- Applies **thresholding** to identify potential flood pixels.  
- Converts flood-candidate pixels → shapefiles (polygonized flood clusters).

### 6️⃣ Apply Conditional Filtering
- Run `flood_extent_filtering.py`:  
- Calculates for each polygon:
  - **Area ≥ 2 acres**  
  - **Mean change ≤ −5 dB**  
  - **Mean slope < 5°**  
- Keeps only polygons meeting all three criteria.  
- Exports final **flood-extent shapefile** for GIS visualization.

| Output Type | Description | Location |
|--------------|--------------|-----------|

| CSVs | Pixel coordinates + VV/VH/DEM values | `geotiff_csvs/` |
| Slope CSVs | Calculated slope values per pixel | `geotiff_csvs/` |
| Initial Flood Extent | Threshold-based flood polygons | Generated by `initial_flood_extent.py` |
| Final Flood Extent | Filtered flood polygons | Output of `flood_extent_filtering.py` |
